# Зафиксированные ограничения и продуктовые фичи

Этот файл нужен как реестр договорённостей, чтобы не потерять их при дальнейшем проектировании.

## Зафиксировано

### Проекты и подписки
- настройки и доступы задаются на уровне проекта
- у каждого проекта отдельный тариф
- у пользователя может быть несколько проектов с разными тарифами
- общий биллинг на несколько проектов не нужен

### Тарифы и add-on
- тарифы настраиваются в БД
- продаётся тариф + отдельные add-on
- площадки могут входить в тариф и могут продаваться отдельно
- тестовый период: 5 дней
- смена тарифа применяется сразу

### Ограничения
- ограничиваются виды площадок
- ограничивается количество площадок / аккаунтов в проекте
- лимиты жёсткие (hard)
- лишние или неразрешённые площадки блокируются, но не удаляются сразу

### Роли
- владелец
- админ
- модератор
- один владелец на проект
- роли фиксированные
- пользователь может иметь разные роли в разных проектах

### Проверки доступа
- Core и Gateway оба участвуют в проверке прав и entitlement
- Gateway проверяет всё:
  - токен
  - принадлежность аккаунта проекту
  - роль пользователя
  - entitlement проекта
  - статус подписки

### Неоплата
- Gateway перестаёт пускать в worker
- аккаунт блокируется, но не удаляется сразу
- есть grace period
- автодаунгрейд не нужен

### Платежи
- оплата автоматическая через эквайринг
- нужен и ручной сценарий
- источник истины: и эквайринг, и Billing
- история платежей обязательна
- возвраты нужны

### Системные админы
- системный админ DDCRM отдельный от проектных ролей
- может вручную менять лимиты и доступы
- может делать override
- нужно заложить будущие внутренние роли DDCRM



### подолнения
- для каждой прощадки обязательное использование прокси (его задаем пользователь при регистрации новой пложадки)
