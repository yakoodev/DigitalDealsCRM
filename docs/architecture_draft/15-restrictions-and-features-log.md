# Зафиксированные ограничения и продуктовые фичи

Этот файл нужен как реестр договорённостей, чтобы не потерять их при дальнейшем проектировании.

## Зафиксировано

### Проекты и подписки
- настройки и доступы задаются на уровне проекта
- у каждого проекта отдельный тариф
- у пользователя может быть несколько проектов с разными тарифами
- общий биллинг на несколько проектов не нужен

### Тарифы и add-on
- тарифы настраиваются в БД
- продаётся тариф + отдельные add-on
- площадки могут входить в тариф и могут продаваться отдельно
- `trial/grace` задаются политикой тарифа
- смена тарифа применяется сразу

### Ограничения
- ограничиваются виды площадок
- ограничивается количество площадок / аккаунтов в проекте
- лимиты жёсткие (hard)
- неразрешённые площадки блокируются, но не удаляются сразу

### Роли
- каноническая матрица ролей и прав: `docs/standards/access-control-matrix.md`

### Проверки доступа
- Core и Gateway оба участвуют в проверке прав и entitlement
- Gateway проверяет токен, claims пользователя, membership/role через cache, принадлежность аккаунта проекту, entitlement проекта и статус подписки

### Неоплата и даунгрейд
- Entitlement переводит проект в `grace/blocked` по политике тарифа
- Gateway блокирует только действия, нарушающие entitlement
- аккаунт не удаляется автоматически

### Платежи
- оплата автоматическая через эквайринг
- нужен ручной сценарий
- источник истины по оплате: Billing
- webhook эквайринга учитываются как входные события
- история платежей обязательна
- возвраты нужны
- webhook обрабатываются с дедупликацией

### Маршрутизация
- `routeKey -> worker binding` хранится в отдельной Route Registry DB
- Core DB не является каноническим источником маршрутизации

### Прокси
- для каждой площадки обязательное использование прокси
- proxy credentials хранятся только в Worker State Storage

### Системные админы
- системный админ DDCRM отдельный от проектных ролей
- права системного админа и правила override определяются в `docs/standards/access-control-matrix.md`
- нужно заложить будущие внутренние роли DDCRM
