# Accounts Manager

## Назначение
Отдельный сервис жизненного цикла аккаунт-воркеров.

## Главная роль
Accounts Manager управляет аккаунтами как runtime-объектами:
- создаёт
- изменяет
- удаляет
- переносит
- балансирует
- проверяет состояние

## Основные обязанности
- lifecycle worker-ов
- health-check
- балансировка
- миграция между серверами
- обновление runtime-конфига
- выбор сервера для размещения поды
- работа со своей БД доступных серверов и runtime metadata
- инициирование регистрации / обновления / удаления route через Gateway

## Важные ограничения
- один worker = один аккаунт
- удаление инициируется Core
- изменение конфигурации делается как update
- сам выбирает сервер из своей БД доступных серверов
- прокси обязателен для каждого аккаунта площадки

## С кем общается
- **Core**
- **Accounts Manager DB**
- **Account API Gateway**
- **Account Worker**
