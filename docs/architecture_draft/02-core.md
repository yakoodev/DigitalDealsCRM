# Core

## Назначение
Бизнес-ядро DDCRM.

## Что хранит и знает
Core знает:
- пользователей
- проекты
- состав участников проекта
- аккаунты площадок как бизнес-сущности
- связь аккаунтов с проектами
- статусы аккаунтов
- routeKey как публичный идентификатор маршрута (без ownership маршрутизации)
- подписку проекта
- ограничения проекта
- доступные платформы

## Что входит в ответственность Core
- работа с пользователями
- работа с проектами
- логическая работа с аккаунтами
- запуск lifecycle-команд через Accounts Manager
- чтение и агрегация данных для frontend
- взаимодействие с Billing
- проверка ограничений через Entitlement Service
- работа с Identity & Access как с источником ролей

## Будущие модули Core
- товары
- единый inbox
- заказы
- аналитика
- автоматизация

## С кем общается
- **Frontend**
- **Accounts Manager**
- **Identity & Access**
- **Billing**
- **Entitlement Service**
- **Core DB**

## Роль Core в проверках
Core участвует в проверке:
- прав пользователя
- entitlement проекта

Но не является единственным местом проверки: Gateway тоже дополнительно проверяет доступ.

## Что не делает
- не проксирует account API
- не работает напрямую с площадками
- не управляет контейнерами
- не выбирает сервер для поды
- не является владельцем `routeKey -> worker binding`
