# Account API Gateway

## Назначение
Отдельный микросервис для доступа к account API.

## Главная роль
Gateway:
- принимает запросы frontend
- сверяет `routeKey`
- дополнительно проверяет токен пользователя
- ограничивает доступ
- проверяет entitlement проекта
- находит нужный worker
- проксирует запрос в worker
- возвращает ответ обратно

## Это не бизнес-ядро
Gateway не хранит бизнес-логику CRM.  
Его основная деятельность:
- проксирование
- авторизация
- ограничение доступа
- маршрутизация
- блокировка доступа к worker при истёкшей подписке или недоступном entitlement

## Кто проверяет доступ
Проверки выполняются **и в Core, и в Gateway**.

## Что проверяет Gateway
- валидность токена
- принадлежность аккаунта проекту
- роль пользователя
- entitlement проекта
- статус подписки
- блокировку проекта

## При неоплате
Gateway перестаёт пускать в worker.  
Аккаунт блокируется, но не удаляется сразу.
