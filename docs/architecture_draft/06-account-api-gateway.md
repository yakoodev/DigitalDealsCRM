# Account API Gateway

## Назначение
Отдельный микросервис для доступа к account API.

## Главная роль
Gateway:
- принимает запросы frontend
- сверяет `routeKey`
- проверяет токен пользователя
- ограничивает доступ
- проверяет entitlement проекта
- находит нужный worker
- проксирует запрос в worker
- возвращает ответ обратно

## Это не бизнес-ядро
Gateway не хранит бизнес-логику CRM.  
Его основная деятельность:
- проксирование
- авторизация
- ограничение доступа
- маршрутизация
- блокировка только для запрещённых entitlement-операций

## Кто проверяет доступ
Проверки выполняются **и в Core, и в Gateway**.

## Что проверяет Gateway
- валидность токена
- claims пользователя из токена
- membership/role через локальный cache (обновляется событиями IAM)
- принадлежность аккаунта проекту
- entitlement проекта
- статус подписки
- блокировку проекта

## При неоплате
Gateway блокирует только операции, нарушающие текущее entitlement-состояние.  
Аккаунт не удаляется автоматически.

## Источник маршрута
Канонический route читается из отдельной **Route Registry DB**.  
Core DB не используется как источник route/binding.
