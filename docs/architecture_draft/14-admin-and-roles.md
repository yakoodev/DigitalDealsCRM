# Админы и роли

## 1. Проектные роли
Внутри проекта используются фиксированные роли:
- владелец
- админ
- модератор

## 2. Системный админ DDCRM
Это отдельная роль уровня всей платформы.

## Что может проектный владелец
- приглашать участников
- удалять участников
- менять роли
- управлять аккаунтами
- менять тариф
- видеть финансы

## Что может проектный админ
- приглашать участников
- удалять участников
- менять роли
- управлять аккаунтами
- менять тариф
- видеть финансы

## Что может модератор
- работать с товарами
- работать с сообщениями
- работать с заказами и прочими операциями аккаунтов
- видеть финансы

## Что может системный админ DDCRM
- управлять тарифами
- управлять лимитами
- вручную менять подписки
- включать или выключать доступы
- видеть все платежи
- блокировать проекты
- включать override для проектов

## UI-следствия
В интерфейсе должны быть:
- экран ролей участников проекта
- экран текущего тарифа проекта
- экран лимитов и их использования
- экран платежей
- экран предупреждений по лимитам
- системная админка DDCRM
