# Админы и роли

Канонический источник ролей и прав:
- `docs/standards/access-control-matrix.md`

## 1. Проектные роли
Состав проектных ролей и их permission-матрица задаются в `docs/standards/access-control-matrix.md`.

## 2. Системный админ DDCRM
Это отдельная роль уровня всей платформы.  
Права системного админа определяются в `docs/standards/access-control-matrix.md`.

## Политика override
Правила override определяются в `docs/standards/access-control-matrix.md`.

## UI-следствия
В интерфейсе должны быть:
- экран ролей участников проекта
- экран текущего тарифа проекта
- экран лимитов и их использования
- экран платежей (для владельца/админа)
- экран предупреждений по лимитам
- системная админка DDCRM
- экран аудита ручных override
