# Frontend

## Назначение
Пользовательский интерфейс DDCRM.

## Основная роль
Frontend работает:
- с **Core** — за бизнес-данными, тарифами, лимитами, проектами, аккаунтами
- с **Account API Gateway** — за вызовом API конкретных аккаунтов

## Основные обязанности
- аутентификация пользователя через Core
- отображение проектов и аккаунтов
- отображение тарифов, add-on, лимитов и текущего потребления
- отображение блокировок и предупреждений
- отправка lifecycle-запросов через Core
- ввод и обновление proxy-настроек при создании/изменении аккаунта площадки
- вызов account API через Gateway
- отображение результатов операций

## Что должно быть видно пользователю
- текущий тариф проекта
- активные add-on
- доступные платформы
- количество использованных / доступных подключений
- дата окончания подписки или тестового периода
- текущие параметры `trial/grace` по активному тарифу
- состояние блокировки проекта
- предупреждение до достижения лимита

## С кем общается
- **Core**
- **Account API Gateway**

## Что не делает
- не управляет worker-ами
- не знает физическое размещение worker-ов
- не знает внутреннюю реализацию площадок
