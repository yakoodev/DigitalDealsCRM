# Identity & Access

## Назначение
Сервис ролей и доступов.

## Типы ролей проекта
Фиксированные роли:
- **владелец**
- **админ**
- **модератор**

## Правила по ролям

### Владелец
- может приглашать участников
- может удалять участников
- может менять роли
- может управлять аккаунтами
- может менять тариф
- видит финансы

### Админ
- может приглашать участников
- может удалять участников
- может менять роли
- может управлять аккаунтами
- может менять тариф
- видит финансы

### Модератор
- может работать с товарами, сообщениями и прочими рабочими сущностями аккаунтов
- видит финансы
- не управляет составом проекта
- не меняет тариф

## Ограничения модели
- в проекте только один владелец
- у одного пользователя могут быть разные роли в разных проектах

## Системные админы DDCRM
Это отдельная сущность, не связанная с проектными ролями.

## Что умеет системный админ DDCRM
- создавать тарифы
- менять лимиты
- включать и выключать фичи
- вручную менять подписку
- видеть платежи
- банить проект
- делать override доступа
