# Entitlement Service

## Назначение
Сервис итоговых ограничений и разрешений проекта.

## Что такое entitlement в этой архитектуре
Это актуальный набор включённых возможностей проекта:
- какие платформы разрешены
- сколько аккаунтов можно иметь
- действует ли trial
- действует ли блокировка
- есть ли grace period
- какие add-on активны

## Что делает сервис
- вычисляет или хранит итоговые ограничения проекта
- активирует их после оплаты
- меняет их сразу после смены тарифа
- хранит историю изменений
- предоставляет проверки Core и Gateway

## Что конкретно ограничивается
- виды площадок
- количество аккаунтов / подключений площадок
- доступные модули
- статус блокировки проекта

## Тип лимитов
Используются **hard limits**.

## Поведение при превышении лимита
- запрещается подключать новые площадки
- запрещается использовать платформы, не входящие в entitlement

## Неоплата
- проект блокируется на уровне доступа к worker через Gateway
- аккаунты не удаляются сразу
- есть grace period

## Override
Системный админ DDCRM может вручную изменить entitlement проекта.

## История
История изменений entitlement должна сохраняться.
